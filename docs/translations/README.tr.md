## Hızlı başlangıç

```bash
npm install @escalated-dev/escalated-adonis
npm install @escalated-dev/escalated
node ace configure @escalated-dev/escalated-adonis
node ace migration:run
```

Ardından `/support` adresini ziyaret edin. AdonisJS v7 ve Node.js 24+ gerekir. [Başlangıç kılavuzu](../getting-started.md) gereken diğer Adonis paketlerini listeler, [yapılandırma](../configuration.md) ise SLA'ları ve eskalasyonları çalıştıran zamanlanmış komutları anlatır.
