<h1 align="center">Escalated for AdonisJS</h1>

<p align="center">
  Dodaj kompletny helpdesk do swojej aplikacji AdonisJS.<br>
  Zgłoszenia, SLA, reguły eskalacji, skrzynka dla agentów i portal klienta, działające na Twojej własnej bazie danych.
</p>

## Funkcje

<table>
<tr>
<td width="33%" valign="top">

**Zgłoszenia**
- Tworzenie, aktualizacja, zamykanie i ponowne otwieranie
- Odpowiedzi w wątkach z przypiętymi notatkami
- Dzielenie, scalanie, łączenie i odkładanie
- Rozmowy poboczne w zgłoszeniu
- Dziennik aktywności każdej zmiany

</td>
<td width="33%" valign="top">

**Przestrzeń robocza agenta**
- Szybkie filtry i zapisane widoki
- Zbiorcza zmiana statusu, priorytetu i przypisania
- Makra i gotowe odpowiedzi
- Działy, tagi i obserwujący
- Widzisz, kto przegląda zgłoszenie

</td>
<td width="33%" valign="top">

**SLA i automatyzacja**
- Cele pierwszej odpowiedzi i rozwiązania
- Wykrywanie naruszeń i ostrzeżenia
- Reguły eskalacji według harmonogramu
- Reguły automatyzacji z warunkami

</td>
</tr>
<tr>
<td width="33%" valign="top">

**Klienci**
- Portal i panel klienta
- Zgłoszenia gości z dostępem przez token
- Weryfikowany dostęp gościa kodem z e-maila
- Osadzany widżet z wyszukiwaniem w bazie wiedzy
- Baza wiedzy, włączana lub wyłączana
- Oceny CSAT po rozwiązaniu

</td>
<td width="33%" valign="top">

**E-mail**
- Poczta przychodząca przez Mailgun, Postmark, SES
- Poprawne wątki w klientach poczty
- Szablony z Twoim brandingiem

</td>
<td width="33%" valign="top">

**Administracja i dostęp**
- Role klienta, agenta i administratora
- Opcjonalne role i uprawnienia
- Opcjonalne SSO: SAML, OAuth 2, OIDC, JWT
- Ustawienia zapisane w bazie danych
- Prywatne, wygasające linki do załączników

</td>
</tr>
<tr>
<td width="33%" valign="top">

**Integracje**
- Podpisane webhooki z dziennikiem dostarczeń
- REST API z tokenami o ograniczonym zakresie
- Wtyczki TypeScript działające w tym samym procesie
- Zbiorczy import danych

</td>
<td width="33%" valign="top">

**Czas rzeczywisty**
- Broadcasting przez Transmit
- Polling jako zapas, gdy jest wyłączony

</td>
<td width="33%" valign="top">

**Języki**
- Teksty ze wspólnego pakietu tłumaczeń
- Nadpisania dla każdego hosta

</td>
</tr>
</table>

## Szybki start

```bash
npm install @escalated-dev/escalated-adonis
npm install @escalated-dev/escalated
node ace configure @escalated-dev/escalated-adonis
node ace migration:run
```

Następnie otwórz `/support`. Wymaga AdonisJS v7 i Node.js 24+. [Przewodnik na start](../getting-started.md) wymienia pozostałe potrzebne pakiety Adonis, a [konfiguracja](../configuration.md) opisuje zaplanowane polecenia, które obsługują SLA i eskalacje.
